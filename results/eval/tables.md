# Results by research question

BM25: Elasticsearch 8.19.15, code-aware tokens, k1 = 1.2, b = 0.75, all query terms (MLT = More Like This with defaults, secondary). CodeBERT: microsoft/codebert-base, CLS embedding, cosine, 512 tokens; zero-shot, and fine-tuned per functionality fold (`embed/codebert.py`; each query scored by a model that never saw its functionality). Micro averages; [lo–hi] = bootstrap 95% CI over queries; paired differences with 95% CI, * = CI excludes 0. Macro averages and all other metrics are in each run's `eval/summary.tsv`. Generated by `eval/eval_tables.py`.
